# Vakaman creative system

The central thesis is **Architecture With Mass**. The website should feel like a digital architectural object with weight, materiality, scale, permanence and memory.

## Physical grammar

- Slow input reads as mass.
- Fast input reads as force.
- Sudden input reads as impact.
- Sustained input reads as tension.
- Proximity can read as attraction.
- Collision can create deformation.
- Release returns the scene through controlled recovery.

Use one coherent physical grammar, not unrelated effects on every section. Stillness is a design tool; intensity must be rare enough to matter.

## Brand world

Void #08080A; Obsidian #0E0D0B; Surface #141210; Ivory #F0EBE1; Stone #2E2A25; Gold #C9A84C. Gold is an event, never wallpaper. Fraunces is display; DM Sans is interface/body. Negative space, asymmetric editorial alignment, deep crops, precise metadata and visual pauses are preferred.

Do not clone a region, a European luxury site or an Awwwards reference. Extract principles, then invent Vakaman's own grammar.

## Content truth

Verified portfolio names and cities live in lib/projects.ts and the client brief. Do not invent amenities, pricing, sizes, awards, testimonials, director biographies, group history, dates, sold-out status, availability or official contact details. Mark missing facts as unresolved inputs.

## Narrative

Hook -> World -> Trust -> Desire -> Story -> Proof -> Escape -> Resolution. Every section must have a narrative job and protect project discovery and enquiry conversion.

## Avoid

Generic black-and-gold templates, equal-card grids everywhere, glassmorphism, gradient blobs, noise-only art direction, gratuitous WebGL, custom cursor dependence, scroll hijacking and effects that announce the technology.
